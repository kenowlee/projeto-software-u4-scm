# projeto-software-u4-scm
Atividade prática de gerenciamento de configuração - Unidade 4

## Gerenciamento de Configuração

Este projeto foi criado para demonstrar o controle de
versão e o gerenciamento de artefatos de software,
conforme a atividade prática da Unidade 4.

## Artefatos

- README.md: documentação do projeto.
- novo.py: exemplo de código-fonte.
- nova_funcionalidade.py: novo artefato de software.

As alterações realizadas serão registradas e
publicadas no repositório GitHub.
